# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 column, dependency, approval, revocation, audit。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `field`、`parent`、`grade`、`day`、`until_day` 排列。最终值单位见阶段结果。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

等级 0–3，取自身和上游的最高值。区间左闭右开。已准许的降级结果继续传播，但不得低于字段自身登记级别。重叠审批单禁止同时生效。

`revocation` 为降级撤销记录，`field` 指向同组的原审批单字段，`day` 为撤销生效日。来源内的撤销按核验日快照判断：核验日早于生效日时历史结果照旧；生效日不晚于核验日时撤回对应降级并沿字段依赖重算。针对已执行批次的晚到撤销通过工作台 `POST /api/runs/<id>/revocations` 受理，生效日不得早于核验日，重算值超过已签标签的分组停止按低级供数。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。
